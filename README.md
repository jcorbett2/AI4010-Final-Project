# Autonomous Deep Learning Agent for Computer Vision

**Author** — Jared  
**Course** — AI 4010, Ohio University, Fall 2026  
**Project track** — Track B 

This project will build an LLM-based agent that inspects a dataset, runs a PyTorch training experiment, and uses validation results to revise its approach and run a second experiment. The same agent will train a separate model for each dataset.

## Datasets

- **Leaf Classification** — Predict the species from a raw leaf image.
- **Denoising Dirty Documents** — Produce a clean document image from a noisy one.
